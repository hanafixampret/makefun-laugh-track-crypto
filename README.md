One line, under 200 characters, about crypto and trading life. A judge model reads the entries two at a time and picks the funniest.

## Entry

> I bought the dip, caught the falling knife, and held the bag — now the group chat calls me exit liquidity, but at least I finally have a title.

## Run

```sh
node main.ts
```

Writes the joke to `/output/entry.txt`.
